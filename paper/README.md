# Paper

`Salmon_Ladder.pdf` is the paper in Japanese (seven pages): Salmon Ladder as the post-stream two-sided read-out, evaluated on OpenOOD v1.5 ImageNet-1K and Four-OOD.

Every number of the method in it comes from the result files archived under `experiments/phase10_11/` (`docs/RESULTS.md`, Section 8 holds the same tables, generated by `tools/make_results_tables.py`). The values of other methods that the paper quotes from their publications are not part of this repository.

This directory names the authors. `tools/make_submission_zip.py` leaves it out of the anonymized archive.
