# Paper

`Salmon_Ladder.pdf` is the paper in Japanese (three pages): two pages of text and one page with the results of the additional experiments.

Every number in it comes from the result files archived under `experiments/`. `docs/RESULTS.md` holds the same tables in full and is generated from those files by `tools/make_results_tables.py`.

This directory names the authors. `tools/make_submission_zip.py` leaves it out of the anonymized archive.
